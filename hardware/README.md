## 2. 接线(就这 4 根)

| 模块引脚 | 接到 ESP32-C3 | 方向 | 说明 |
|---|---|---|---|
| **VCC** | `3V3` | — | **不要接 5V**,理由见 §4 |
| **GND** | `GND` | — | 必须共地,否则串口必乱码 |
| **TXD** | `GPIO4`(UART1 RX) | 模块 → ESP32 | 交叉:`TXD` 对 `RX` |
| **RXD** | `GPIO3`(UART1 TX) | ESP32 → 模块 | 交叉:`RXD` 对 `TX` |

```
   YS-RF34DL              ESP32-C3(0.42" OLED 板)
   ┌────────┐             ┌──────────────────┐
   │ VCC ───┼─────────────┤ 3V3              │
   │ GND ───┼─────────────┤ GND              │
   │ TXD ───┼─────────────┤ GPIO4  (UART1 RX)│
   │ RXD ───┼─────────────┤ GPIO3  (UART1 TX)│
   └────────┘             └──────────────────┘
        └── 天线 17–23cm
```

## 3. 为什么是 GPIO3 / GPIO4

| GPIO | 本板上的实际用途 | 模块串口能用吗 |
|---|---|---|
| 3 / 4 | 空闲,且已引出排针 | ✅ 本方案用 |
| **5 / 6** | **板载 OLED 的 I2C(SDA/SCL),焊死在板上** | ❌ 不能挪 |
| 18 / 19 | 原生 USB D−/D+(控制台) | ❌ |
| 20 / 21 | UART0(备用控制台) | ❌ 与命令行抢 |
| 8 / 9 | 板载 LED / BOOT 键(strapping) | ❌ 上电电平会被按键/灯影响 |
| 2 | strapping | ❌ |

## 4. 供电与电平:为什么是 3.3V(★ 上机前必读)

模块说明书两处自相矛盾:核心参数写 **3.3–5V**,引脚定义写 **VCC 4.5–5.5V**。
本方案选 **3.3V 直连**,理由:

1. **VCC 与逻辑电平必须一致**。5V 供电时模块 TXD 输出 5V,而 ESP32-C3 的 GPIO 绝对最大只有 3.6V —— 直连会打坏 GPIO4。
2. 反过来,ESP32 的 3.3V 高电平低于 5V TTL 的 VIH(≈3.5V),5V 供电时模块可能收不到可靠高电平。
3. 3.3V 下两侧天然匹配,**零额外器件**。注意:2026-11-14 抓包时模块的 VCC 接法没有记录,那条证据只证明「解码链路通」,不证明「3.3V 已可用」。

**代价**:3.3V 低于引脚定义的 4.5V,发射功率与距离没有保证 —— 解码已实测可用,**发射未验证**。

**升级路径(只在实测距离不够时走)**:模块改 5V 供电;`TXD → GPIO4` 串 **1kΩ/2kΩ 分压**(分压后 ≈3.3V);`GPIO3 → 模块 RXD` 经 **5V 缓冲**(74HCT1G125,VIH≈2.0V)或 **BSS138 双向电平转换**;共地。

**禁止**:

- 5V 直接进 GPIO3/GPIO4。
- 在没量 TXD 空闲电压前就把 TXD 接到 GPIO4。

## 5. 上电前检查表

| # | 检查 | 判据 | 不对时的后果 |
|---|---|---|---|
| 1 | 断电接线,VCC/GND 方向 | 目视 + 万用表通断 | 反接烧模块 |
| 2 | 模块 VCC–GND 电压 | **≈3.3V** | 低于 3.0V 可能不稳 |
| 3 | 模块 **TXD 空闲电压**(不接 GPIO4 时量) | **≈3.3V**(允许 3.0–3.5V) | >3.6V 绝不能接 GPIO4 |
| 4 | TXD/RXD 是否交叉 | 模块 TXD→GPIO4,模块 RXD→GPIO3 | 不交叉则完全没数据 |
| 5 | 天线已接 | 目视 | 不接只有 1–5m |
| 6 | 共地 | 万用表 VCC 与 GND 之间 3.3V | 乱码/丢帧 |
| 7 | 上电后串口有横幅 | `# RF-Lab fw=0.4.0` | 见 `firmware/README.md` 排障 |

## 6. 天线

- 17–23cm 单芯线,尽量**竖直**;卷起来能用但会缩短有效长度、降低效率。
- 远离金属、电池、USB 线束和手;**不要**贴在模块 PCB 上盘成一团。
- 315M 波长 ≈95cm、433M ≈69cm,单芯 17–23cm 属短天线,靠模块本身的匹配网络工作;换更长/带底座天线前先确认接口。

## 7. 风险表

| # | 风险 | 后果 | 处理 |
|---|---|---|---|
| 1 | 3.3V 低于引脚定义 4.5V | 发射功率/距离不足 | 先按 3.3V 验证;不够走 §4 的 5V 改造 |
| 2 | 5V 直连 GPIO | 打坏 GPIO,甚至整板 | 禁止;TXD 必须实测 |
| 3 | 模块常带电、无发射硬门控 | 固件发出的每帧都是真发射 | 不用时拔 USB;不要在敏感场合带电联调 |
| 4 | 固定码本身可复制 | 复制成功 = 该设备不安全 | 只测自有设备;结论只对固定码成立 |
| 5 | 模块行为未公开(时长单位/应答时机) | 长发/停止/改波特率可能不按预期 | 每步看应答;`INFO` 的 stray/resync 计数是失败度量 |
| 6 | 天线不接 | 距离掉到 1–5m | 接天线再测距离 |
