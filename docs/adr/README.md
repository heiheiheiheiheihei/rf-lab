# ADR 索引

本目录存放 **架构决策记录**(Architecture Decision Record):只回答「为什么这样定」,
不复述规格、不维护状态。射频/命令语义仍以 [`../00-mvp.md`](../00-mvp.md) 为准,
UI 以 [`../01-ui.md`](../01-ui.md) 为准,计划以 [`../02-plan.md`](../02-plan.md) 为准。

## 规则

1. **一篇一个决策**,文件名 `ADR-NNN-<slug>.md`;编号不复用。
2. 状态只取:`提议` → `接受` → `取代`(被取代时在头部写 `取代: ADR-NNN`,原文不改)。
3. 决策变了**新开一篇**,不回头改写已生效的 ADR;勘误只加「修订记录」小节。
4. 每篇必须有:背景、决策、后果、验收、重访条件;涉及外部代码时写清许可边界。
