## 4. 关键判断

1. **为什么配网后 AP 保持,重启才 STA-only?**
   配网请求来自浏览器;如果成功后立刻关 AP,提交请求的浏览器会被踢掉、看不到结果。
   本次验收特意重启后再看:重启后 `ap_on=0`,证明 STA-only 生效。
2. **为什么主机 curl 一开始 503?**
   本机 `http_proxy` 环境变量把内网 IP 也送进了代理。必须 `--noproxy '*'`(或
   `NO_PROXY=<ip>`);这不是设备问题。设备 `ping` 2–3ms、直连 200 已排除。
3. **为什么 DHCP 会从 .11 变成 .117?**
   路由器重新分配/租约变化;设备以最新 `sta_ip` 为准。OLED `LAN OK` 与 `INFO` 同源。
4. **AP 关闭的代价**
   STA 模式下附近连不到 `RF-Lab-XXXX`;回退/配网时自动重新打开。这是有意的取舍
   (减少空口占用/暴露面),不是故障。
