## 2. 迁移内容

- 仓库从 private 切到 public;GitHub Pages 免费套餐可用。
- Pages 采用 **Actions artifact** 发布,不建 `gh-pages` 分支;工作流把 `site/` 上传后由
  `actions/deploy-pages` 发布。
- 站点 URL 从 Cloudflare 的 `rf-lab-388.pages.dev` 换成
  `https://heiheiheiheiheihei.github.io/rf-lab/`。
- `canonical`、`og:url`、`og:image`、`twitter:image`、`robots.txt`、`sitemap.xml`
  同步改为 GitHub Pages 绝对 URL。
- 页脚文档位仍是页内锚点;完整规格现在在公开仓库里可访问。
- 旧 Cloudflare Pages 项目不删除,保留为历史镜像;搜索结果/旧链接可能仍指向它。

## 3. 复现 / 检查

```bash

  --accept-visibility-change-consequences

# 发布:push master 或手动
```
