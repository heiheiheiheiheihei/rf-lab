## 4 拒绝路径

| 用例 | 命令 | 实测 |
|---|---|---|
| 错 token | `POST /api/ota` + `X-RFLAB-OTA: 00000000` | **401** `bad or missing token`;设备仍 `ui=91014e8f` |
| 随机镜像 | 200KB `/dev/urandom`,正确 token | **500** `write ESP_ERR_OTA_VALIDATE_FAILED`;仍运行旧槽 |
| 上传中断 | `timeout 2 curl --limit-rate 150k ...` | curl 124;设备仍 `ui=91014e8f`;`/api/state.ota={armed:1,pct:0,phase:"error",slot:0,next:1}`;token 未被消耗 |
| HTTP 尝试 arm | `POST /api/cmd {"cmd":"OTA"}` | 202 入队,但执行 `ERR OTA is serial-only`;`armed` 仍 0 |
| `OTA OFF` | 串口 | `OK ota=off`;`armed=0, phase=idle` |

中断只发生在 socket 层,**没有做真断电**:写入的是非运行槽,按设计不影响启动;但“拔电瞬间”
未实测。
